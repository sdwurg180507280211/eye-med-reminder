# eye-med-reminder

眼科用药提醒助手 Flutter MVP，支持 Android / iOS。参考本地 `eye_medication_demo_v18.html` 的蓝白色页面、患者档案、处方录入、计划确认、我的、历史详情和小狗提醒流程。

## 运行

使用 **Flutter 3.47.6 stable / Dart 3.13.5**（本次验证版本）。Android 项目需要 JDK 17、Android SDK（compileSdk 由 Flutter 指定，至少35）及相应 NDK；iOS 需要 macOS、Xcode、CocoaPods（不支持 Swift Package Manager 的插件由 Flutter 使用 CocoaPods 集成），最低 iOS 15。

```sh
git clone https://github.com/sdwurg180507280211/eye-med-reminder.git
cd eye-med-reminder
git checkout codex/flutter-mvp
flutter pub get
flutter run
```

```sh
flutter analyze
flutter test
flutter build apk --debug
# macOS 上运行
flutter build ios --simulator --debug
```

首次运行创建姓名和6位数字密码的档案。添加药物，逐项填写医嘱信息、时间与疗程，确认后在“我的”查看今天计划。后台点击系统通知打开实际提醒；前台到点直接进入提醒页面。**没有“测试用药提醒页面”按钮**。

## 已完成

- 姓名 + 6位数字密码登录 / 创建，确认密码与输入验证，独立 patient_id；同名患者通过各自密码区分。PBKDF2-HMAC-SHA256、随机盐、100000次迭代；密码不以明文保存。
- 档案及确认计划写入 Android Keystore / iOS Keychain 支持的安全存储。退出保留记录，取消当前档案通知；再次登录恢复记录并重新安排通知。重启应用需登录。
- 拍摄 / 相册入口、照片预览、复制到应用私有目录，确认后历史可查看照片；权限失败可手动录入。照片不会上传，照片文件本身未单独加密。
- 药名、记录/开始日期、眼别、剂量、频次、天数、08:00 / 12:00 / 17:00 多选、自定义时间；无自动填充医嘱剂量。时间数量必须匹配频次，“每N小时”检查24小时循环间隔。
- 确认前可修改、删除、调整顺序；同原始时间、同一天处于疗程内的多药依顺序 +10分钟，不同处方也参与排序（旧处方在前）。跨午夜保留次日日期；疗程结束后不再提醒。拦截重叠疗程中同名、重叠眼别、同时间的重复药物。
- 复查日期及提前3/2/1天多选；所选日期08:00提醒，不选则不提前提醒。
- “我的”今天计划、复查摘要、历史与详情、药物说明入口。
- 本地绘制的小狗嘴部动画资源位 + 系统普通话 TTS 播报患者姓名、药名、眼别、剂量。语音失败/超时保留静态小狗、核心文字、药物说明与结束提醒按钮。结束提醒只关闭页面，不记录已用药。
- Android / iOS 本地通知、通知点击路由（包括冷启动登录后恢复）、前台到点提醒；时区取设备设置，使用本地时钟。
- `DrugCatalog.lookup(exactName)` 为 Excel 资料库查询接口。未接入时明确显示无资料，不模拟说明书，也不从资料库推断剂量。
- 自动验证：时间错开、排序、跨午夜、疗程边界、复查多选、通知数量上限、序列化、患者隔离与重开恢复、密码散列、输入校验、语音失败兜底。

## 对原型的修正与当前边界

- 不模拟 OCR、不注入示例药物，不预填剂量、眼别、频次或疗程。记录日期同时作为疗程开始日期。
- 确认计划保存为独立历史记录；新增处方不覆盖旧处方。尚未提供已确认计划的修改/停药入口，确认前请核对，疗程内如需调整应在后续版本接入明确的变更流程。
- 提醒只在真实到点或点击真实通知后出现。应用在后台/被关闭时使用系统通知；系统限制不允许保证自动弹出全屏小狗或后台播放动态语音。点击通知后才播放动画语音。
- Android 需允许通知与精确闹钟。未授予精确闹钟时降为非精确通知，并在“我的”说明可能延迟。厂商省电、勿扰、静音、强制停止会影响触达，需真机验证。
- 为兼容 iOS 64条待办通知上限，只排入最近 **60条**（包括复查）。每次登录、确认、回到前台补排；“我的”显示排期截止，需在截止前重新打开应用。无限期不打开应用的续排暂未实现。
- 前台恢复仅补弹最近5分钟内的到点提醒，避免一次弹出大量过期提醒；历史系统通知可通过点击查看。系统时间/时区修改后需回到前台重排。
- 草稿暂存当前会话，确认后才持久化。当天实际时间按当天仍在疗程内的药物计算；详情的首日时间是按该处方内部顺序计算的参考时间，最终以“我的”当天计划为准。
- 纯本地档案，不是服务端账号，无密码找回、云同步或医生后台。卸载后数据恢复不可保证。

4. 长疗程通知续排、真机可靠性及资源失败测试；正式 Android 签名和 iOS 签名/发布配置。

## 代码布局

`lib/main.dart` 页面与前台流程；`models.dart` 档案/计划及时间计算；`storage.dart` 本地安全存储与密码校验；`notifications.dart` 系统通知；`drug_catalog.dart` 资料库接口；`test/` 自动验证。
